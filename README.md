# egs-caseb-battery-arbitrage
# EGS Coursework – Case B: Grid-Scale Battery in Electricity Markets

This repository contains the MATLAB implementation for Case B of the EGS individual coursework.

## Scope
- Base case: day-ahead electricity arbitrage
- Extension: ancillary market stacking with reserve capacity reservation

## Main scripts
- `main_caseB.m` – runs the base-case workflow
- `main_caseB_stacking.m` – runs the stacking extension workflow
- `compare_caseB_base_vs_stacking.m` – compares the two cases

## Data
The model uses the coursework dataset:
`caseB_grid_battery_market_hourly.csv`

## Notes
The report PDF contains the mathematical formulation, verification summary, key results, and engineering discussion. Additional plots are provided in the appendix.
